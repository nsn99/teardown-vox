# Тирдаун

Воксельная игра-головоломка про ограбления с тотальной разрушаемостью.
Разведка уровня → пробитие кратчайшего пути → расстановка транспорта →
первая проводная цель включает сигнализацию → ровно шестьдесят секунд →
побег.

Играется в браузере. Друзьям ничего ставить не надо — только ссылка.

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 354 теста
npm run test:cov   # с порогами покрытия
npm run smoke      # прогон в настоящем браузере со скриншотами
```

## Что уже работает

**Физическое ядро** (`packages/core`)

- Воксельный мир из форм и тел, DDA-трассировка луча, RLE-сериализация карт.
- Разрушение четырьмя кистями (сфера, бокс, капсула, конус) с моделью
  «сила инструмента против прочности материала»: кувалда не берёт сталь
  ни за двести ударов, паяльная лампа берёт.
- **Структурная целостность.** Флад-филл от якорей отделяет всё, что
  потеряло связь с землёй, в динамические обломки. Поверх — модель
  нагрузок: сжатие и изгиб с честным распределением веса по всем опорам
  куска. Подпилил колонну — плита села; отрезал балку — сел пролёт;
  деревянная консоль в четыре метра отламывается сама, стальная держит.
- Распространение огня: детерминированный клеточный автомат, обугливание,
  влага от огнетушителя, ветер.
- Твёрдые тела на Rapier: компаунд-коллайдеры из жадно склеенных боксов,
  огрубление крупной геометрии, урон от удара по потере скорости.
  Тот же интерфейс реализует headless-дублёр — на нём гоняются тесты,
  и WASM для них не нужен.

**Игровая логика** (`packages/game`)

- Семь инструментов из дизайн-документа, по четыре ступени у каждого.
- Конечный автомат ограбления с таймером ровно на 60 секунд: доставка на
  59.9-й засчитывается, на 60.0 — вертолёт и провал без выплаты.
- Контроллер игрока, который сам заходит на завалы; техника, пробивающая
  стену на разгоне и расчищающая завал отвалом.
- Экономика, прокачка в хабе, сохранение профиля и рекордов, песочница.

**Рендер и приложение** (`packages/render`, `apps/web`)

- Жадное меширование с затенением в углах, чанковый ремеш по бюджету.
- Частицы осколков, искр, дыма и огня; динамический свет от очагов.
- Карта M «Порт»: набережная, склад, офис, кран, причал, контейнеры,
  гавань с водой. Пять целей, две из них на кабеле сигнализации.

## Устройство

```
packages/core    физика: воксели, разрушение, целостность, огонь, тела
packages/game    правила: инструменты, миссия, персонаж, техника, карты
packages/render  отрисовка: меширование, сцена, эффекты
apps/web         приложение: ввод, HUD, хаб, игровой цикл
tools/issues     волны issues и их заливка в GitHub
tools/smoke      прогон в браузере со скриншотами
```

Ключевое разделение: **ядро и логика не знают про DOM и WebGL.** Поэтому
физика и правила покрыты обычными юнит-тестами (99% строк, 95% ветвей),
а рендер проверяется отдельно — скриншотами и прогоном в браузере.

Подробнее: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md),
план работ: [`docs/ROADMAP.md`](docs/ROADMAP.md).

## Управление

| | |
|---|---|
| WASD | движение |
| Shift / Ctrl | бег / присед |
| Пробел | прыжок, в воде — всплытие |
| ЛКМ | применить инструмент |
| ПКМ | детонатор |
| E | взять / положить цель |
| F | сесть в технику / выйти |
| 1…7 | выбор инструмента |

| R | перезапуск |
| Esc | меню |

## Волны issues

Работа нарезана на 13 волн и 57 задач с критериями приёмки —
`tools/issues/waves.yaml`.

```bash
npm run issues:plan                                    # посмотреть план
GH_TOKEN=… npm run issues:sync -- --repo owner/name    # залить в GitHub
GH_TOKEN=… npm run issues:sync -- --repo owner/name --close-done
```

Скрипт идемпотентен: повторный запуск обновляет существующие issues,
сопоставляя их по заголовку, а не плодит дубликаты.

## Приёмка

1. Физика и игровая логика — только через тесты. Пороги 90% строк и 85%
   ветвей по `packages/core` и `packages/game` роняют сборку.
2. Рендер — через `npm run smoke`: прогон в Chromium, проверка на чёрный
   и на пересвеченный кадр, реальное разрушение, скриншоты в `shots/`.
3. Любая случайность идёт через сид. Два прогона с одним сидом дают
   идентичное состояние мира, и на это есть тесты.
