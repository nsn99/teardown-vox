# Доски: ввод и крепления — 25 сентября 2026

Пользовательская проверка: вместо пандуса появляются короткие деревянные
блоки и падают. Скриншоты показывают выбранный инструмент «Доски» и обрезки.

Причины:

1. Основное действие вызывалось каждый кадр удержания ЛКМ. Первый и второй
   конец выбирались при одном физическом нажатии, почти в одном месте.
2. Новая доска была отдельной формой без якорей. Связь с поверхностями,
   на которые пришлись оба клика, не сохранялась; структурный анализ её ронял.
3. Расходник списывался даже при совпавших точках и отсутствии созданной доски.
4. Диагональные пандусы кренились поперёк; при подъёме на ступень персонаж
   зависал над опорой и мог соскользнуть вбок, застряв у контейнера.

Исправления:

- Доски используют событие нового нажатия, а не удержание. Другие инструменты
  сохраняют непрерывное действие; быстрый одиночный клик также учитывается.
- При выходе из захвата мыши и потере фокуса сбрасывается ввод.
- Слишком близкие точки не расходуют доску; первая точка остаётся выбранной.
- Концы связываются с конкретными вокселями неподвижных опор. Крепления
  перепроверяются структурной системой; после разрушения обеих опор доска падает.
  Произвольные доски не помечаются навечно стоящими на земле.
- Подсказки объясняют выбор второй точки, отсутствие поверхности и неверную длину.
- Ширина пандуса остаётся горизонтальной. После шага вверх персонаж сразу
  прижимается к опоре; существующий тест подъёма к сумке на контейнере проходит.

Проверки:

- `npm run test:cov`: 36 файлов, 588 тестов прошли; покрытие строк 98,6%.
- `npm run build`, `npm run typecheck`, `npm run lint`: успешно.

- Тесты совпавших точек, сохранения расходника, креплений и потери опор.
- Chromium/SwiftShader: первое удержание 1,2 с не создаёт ни одной доски;
  второе удержание 1,2 с создаёт ровно одну, она сохраняет опоры.
- Персонаж без прыжка поднялся по пандусу на платформу высотой 1 м.
  Проверка использует клавиатуру и события мыши canvas, простую тестовую сцену
  внутри собранной игры и настоящий Rapier. Это не проверка ввода на Mac.
- Браузерный сценарий: `node tools/smoke/planks.mjs` после сборки.
