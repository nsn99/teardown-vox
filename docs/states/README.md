# Контрольные ролики состояний — 25 сентября 2026

Свежие записи сравнили с прежними по начальному и конечному кадрам. Намеренные
изменения: изолированные стенды, дневной свет, материал отражает небо, стекло
разбивается листом, земля осыпается, обычное разрушение даёт частицы.
Подробности и ограничения приёмки — в `../verification-2026-09-25.md`.

Фиксированный шаг симуляции 1/60 с, запись 960×540 при 10 кадрах/с.
Стенды: medium, 4 секунды; склад: low, 9 секунд (программный SwiftShader).
Частота записанного видео не измеряет реальный FPS игры.

Воспроизведение после `npm run build`:

```sh
npm run states -- --skip-collapse
npm run states -- --only collapse --collapse-quality low
```

Каждый стенд начинает чистую сцену; инструменты подняты до максимальной ступени.
Остаток считает воксели в исходном теле, без отделившихся обломков.
Статистика 1296 → 144 означает, что в исходном теле осталась несущая плита.
Огнетушитель применяется к горящему дереву; краска и доски — к кирпичу.

`обрушение-склада.webm`: четыре сектора подрезают несущие стены и колонны;
отделено 215 405 вокселей. Камера теперь показывает склад вместо пустого неба.
К концу записи верх склада остаётся крупной наклонённой оболочкой. Это запись
отделения от опор, **не подтверждение полного сноса до фундамента**.
Четыре сектора охватывают все опоры, а не только геометрические углы.

Ручной чек-лист не пройден целиком: остаются мягкий загиб пластика, полный снос,
вторичные разрушения, минутная плавность на целевом GPU, звук и управление.
