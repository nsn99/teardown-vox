# Таран и физические обломки — 1 октября 2026

Исправленная версия v2 подготовлена на `0bf06e7` с учётом присланного
1 октября `punchThrough()`: в нём уже используется продольная капсула.
Контекст изменения этой функции взят из присланного кода. Остальная
рабочая копия недоступна; совместимость проверяется командой
`git apply --check`. Сборку на компьютере пользователя надо проверять отдельно.

## Изменения

- Обычный таран использует капсулу: ширина скола меняется по высоте.
  Размер учитывает габариты щупа, чтобы верхние углы нового проёма не
  остановили машину сразу после разрушения кирпича.
- Часть удалённых вокселей становится физическими обломками. Сохраняются
  материал, окраска и мировые координаты, включая повёрнутые формы.
  Куски получают скорость по направлению удара и подхватываются Rapier.
- За один вызов создаётся не больше 32 тел размером до 4×4×4 вокселей.
  Избыток остаётся пылью и частицами; листва твёрдых обломков не создаёт.
- Выбитые куски не блокируют щуп и повторно не дробятся тем же бампером.
- После разрушения проход проверяется снова. Снятое дерево рядом со
  сталью не позволяет проехать сквозь сохранившуюся сталь.
- Передний отвал не используется как задний бампер при движении назад.

Конструктор техники, карта, настройки катера, задний щуп и существующие
тесты не меняются. Применение v2 проверено на копии с присланной функцией,
сдвигом строк до номера 546 и отдельной правкой заднего щупа.
Содержимое вне `punchThrough()` и `scanIgnoring()` сохранилось побайтово.

## Проверки

- Для v2 на проверочной копии повторно прошли 28/28 профильных тестов,
  проверка типов, линтер и production build.
- `npm run test:cov`: 598/598 тестов, 38 файлов; строки — 98,63%,
  ветви — 92,27%. Новые проверки включены в этот полный прогон.
- `npm run test:perf`: 10/10; прогон выполнен после завершения покрытия.
- Новые тесты: скол, движение после удара, препятствие из двух материалов,
  порог скорости, повторный контакт с кусками, Rapier и сохранение материала.
- Настоящий Rapier/WASM перемещает куски и удерживает непустые воксели
  над полом через две секунды. Это не визуальная проверка в браузере.
- Проверки типов, линтер и production build прошли.
- Production preview отдаёт страницу с HTTP 200.

## Применение

Применять в исходной рабочей копии `/Users/pavel/teardown-vox-check`.
Сначала проверить патч; при несовпадении контекста исходники не менять.
После применения выполнить новые и существующие тесты транспорта,
затем сборку и запуск preview. Ручная приёмка: разгон и таран кирпичной
стены, движение через пролом, видимое падение кусочков и серия повторных ударов.
