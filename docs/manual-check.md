# Чек-лист ручной проверки

Автотесты проверяют, что игра считает правильно. Этот список — про то,
что она правильно **выглядит и ощущается**. Ни один тест не скажет, что
обрушение читается как обрушение, а не как исчезновение вокселей.

Проходить перед выпуском и после любой правки разрушения, света или
физики. Отмечать в копии этого файла, а не в самом файле.

Эталонные ролики лежат в `docs/states/`: короткая запись «цел →
повреждён → разрушен» на каждый материал и каждый инструмент плюс запись
полного обрушения склада. Это справочник — с чем сравнивать, когда
кажется, что «стало не так».

Свежие снимаются командой `npm run states` и кладутся в `shots/states/`
(этот каталог не в репозитории). Сравнивать надо свежий ролик с
эталонным; если расхождение осознанное, эталон заменяется в том же
коммите, что и правка.

---

## 1. Разрушение по материалам

Для каждого материала: поставить стенку, ударить подходящим
инструментом, сравнить с роликом из `docs/states/материал-*.webm`.

- [ ] **Кирпич** — крошится кусками, а не растворяется. Края скола рваные.
- [ ] **Бетон** — берётся только взрывом и техникой, кувалдой сопротивляется.
- [ ] **Камень** — тяжёлые обломки, падают недалеко.
- [ ] **Земля** — осыпается, не держит форму навесом.
- [ ] **Доска и дерево** — дробовик сносит вчистую, кувалда проламывает.
- [ ] **Металл** — только горелка и взрыв; кувалда даёт вмятину, но не дыру.
- [ ] **Тяжёлый металл** — не берётся ничем, кроме заряда вплотную.
- [ ] **Стекло** — рассыпается целым листом, а не по одному вокселю.
- [ ] **Пластик** — мягко, с загибом краёв.
- [ ] **Листва** — сносится любым касанием, обломков не даёт.
- [ ] **Кабель** — перебивается, и сирена включается ровно один раз.

## 2. Инструменты

Сравнить с `docs/states/инструмент-*.webm`.

- [ ] **Кувалда** — радиус растёт со ступенью, звук совпадает с ударом.
- [ ] **Дробовик** — конус, а не луч; стекло и доски сносит вчистую.
- [ ] **Взрывчатка** — заряд виден на стене, детонатор рвёт все сразу.
- [ ] **Горелка** — режет металл и поджигает то, что горит.
- [ ] **Баллон с краской** — красит, но не разрушает.
- [ ] **Огнетушитель** — гасит огонь и не трогает геометрию.
- [ ] **Доски** — первая точка, вторая точка, мост встал и держит вес.
  Удержание кнопки на первой точке не создаёт обрезков. После отпускания
  вторым нажатием строится одна доска; по наклонной доске можно подняться.
  После разрушения обеих точек крепления доска падает.
- [ ] Переключение по цифрам и колесу, откат между ударами заметен.

## 3. Массовое разрушение

Сравнить с `docs/states/обрушение-склада.webm`.

- [ ] Подрубить четыре угла склада — крыша идёт вниз, а не висит.
- [ ] Обломки падают и остаются лежать, не проваливаются сквозь пол.
- [ ] Обрушение второго порядка: упавшая плита проламывает перекрытие.
- [ ] Кадр не встаёт колом: картинка живёт всё время обрушения.
- [ ] Пыль и обломки появляются там, где рвётся, а не по всей карте.
- [ ] Через минуту после обрушения игра идёт с той же плавностью.
- [ ] Обрушить склад полностью — до фундамента. Ничего не зависает в воздухе.

## 4. Свет и погода

- [ ] Внутри целого склада темно; пробитая крыша даёт пятно света на полу.
- [ ] Прожектор на кране не светит сквозь стены.
- [ ] День, сумерки, ночь: бетон остаётся бетоном, не выгорает в белое.
- [ ] Дым садит видимость и рассеивается; в дыму прицел уводит.
- [ ] Огонь освещает то, что рядом, и гаснет от огнетушителя.

## 5. Управление и камера

- [ ] Мышь без рывков и без накопления, чувствительность одинакова по осям.
- [ ] Камера от третьего лица не заходит в стену в тесном углу.
- [ ] Тряска от взрыва не мешает целиться: картинка дёргается, прицел нет.
- [ ] Посадка и высадка из техники: игрок не оказывается внутри геометрии.
- [ ] Прыжок, приседание, вода — переходы без залипаний.

## 6. Миссия

- [ ] Сейф руками не поднять; техникой — увозится.
- [ ] Перерезанный кабель включает сирену один раз, таймер идёт с него.
- [ ] Три пути отхода проходятся за таймер, каждый своим маршрутом.
- [ ] Сумка на контейнере берётся только с пандуса из досок.
- [ ] По нулю таймера приходит вертолёт и находит игрока.
- [ ] Провал и успех считаются одинаково честно; деньги начисляются раз.

## 7. Карты со стороны

- [ ] Своя карта `.json` бросается в окно и запускается.
- [ ] Битая карта называет поле, в котором ошибка, а не «что-то не так».
- [ ] Файл `.vox` из MagicaVoxel открывается и красится по палитре.

---

## Что делать с найденным

Расхождение с роликом — это баг, даже если тесты зелёные. Заводить issue
с двумя записями: «как было» из `docs/states/` и «как стало». Разбор по
описанию словами занимает вдвое больше времени и половину случаев
заканчивается спором о том, что имелось в виду.
