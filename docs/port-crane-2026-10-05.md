# Портовый кран — 05.10.2026

## Что исправлено

Старая модель состояла из толстой тяжёлой стальной башни с прямоугольной
кабиной и коротким выступом вместо стрелы. Под основанием была вода:
грунт в этом участке заканчивается на высоте −1,8 м, а кран начинался на нуле.

Новая модель в `packages/game/src/levels/port.json` содержит:

- причал на уровне берега, бетонные опоры и усиленные стойки до дна;
- открытую башню из четырёх стоек с горизонтальными связями и раскосами;
- длинную наклонную ферменную стрелу, противовес и лебёдку;
- два подъёмных троса и подвесной крюк;
- пять лестничных пролётов, площадки и проход в остеклённую кабину;
- кресло оператора, пульт, экран, кнопку и рычаг;
- корпус прожектора в точке существующего света, направленного на склад.

Причал и кран находятся в одной структурной форме. Неуязвимый фундамент
есть только в нижнем слое опор на дне. У стоек, раскосов, стрелы, кабины
и тросов обычные разрушаемые материалы. Усиленные внутренние уголки стоек,
нижние пояса стрелы и нагруженные соединения выполнены из тяжёлой стали;
наружные части, большая часть фермы и лестница — из обычного металла.
Подъёмные тросы тоже металлические: разрыв не включает сигнализацию.

## Проверки

`packages/game/test/port-crane.test.ts` проверяет реальную геометрию карты:

1. Полный расчёт нагрузок и связности не даёт разрушений или висящих деталей
   на старте; опоры соприкасаются с дном.
2. Обычный контроллер персонажа проходит от берега по лестнице в кабину,
   без телепортации, прыжков и приседания.
3. Базовый контактный заряд делает отверстие в наружной стороне стойки.
4. Базовый заряд разрывает подъёмные тросы; крюк становится падающим обломком.
5. Обычная паяльная лампа режет нижнюю стальную раскосину.
6. Девять зарядов максимальной ступени разрушают четыре усиленные опоры
   с двух сторон и нижний пролёт лестницы. Верх отделяется; Rapier за четыре
   секунды опускает стрелу и разбивает конструкцию на части. Проверяется
   высота настоящих вокселей, а не только положение тела или его AABB.

Сценарий попадания в кран в `structure-incremental.test.ts` перенесён на
переднюю левую стойку новой модели. Полный и инкрементальный пересчёт
по-прежнему сверяются между собой.

```bash
npm test -- packages/game/test/port-crane.test.ts packages/game/test/structure-incremental.test.ts
npm run test:cov
npm run test:perf
npm run typecheck
npm run lint
npm run build
```

## Ручная приёмка

- Подойти со стороны берега: между стойками виден вход на лестницу;
  причал соединён с сухой площадкой на одной высоте.
- Осмотреть кран с берега и воды: стрела выступает над гаванью, крюк
  висит на тросах, опоры уходят в воду до дна.
- Подняться в кабину: дверь открыта, внутри есть кресло и пульт,
  наружу можно смотреть через окна.
- Попасть зарядом в наружную сторону стойки: остаётся видимое отверстие.
  Нижние серые раскосы режутся лампой; усиленные узлы требуют взрывчатки.
- Разрушить оба троса: крюк падает. Для полного обрушения убрать все
  нижние несущие связи, включая связанный с верхом лестничный пролёт.
- Проверить, что движение катера перед причалом и проезд к воротам склада
  остаются свободными.

Браузерную приёмку освещения и плавности нужно выполнить в игре;
геометрический предпросмотр не воспроизводит игровой свет.
